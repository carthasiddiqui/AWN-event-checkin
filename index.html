How to export from Eventbrite

  1. On a computer, log into Eventbrite and go to your event → Event Reports
  2. Scroll down to the Attendees section
  3. Select Custom Questions Responses
  4. Click CSV about halfway down the page
  5. Email the file to yourself
  6. On your phone, open the email and save the attachment to Files / iCloud Drive
  7. Tap Select CSV file above and choose it
  8. If the file picker doesn't work, add this page to your Home Screen first (banner above)

For the technically savvy, you can do this from your phone by requesting the desktop version of the website.
